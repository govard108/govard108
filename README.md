## I build production systems for the AI-native era

I’m **Aleksey Ahmedov** — an **AI Product Engineer** and **Agentic Systems Builder** focused on turning LLMs, tools, context and workflows into real products.

My work sits at the intersection of:

- **AI agents & orchestration** — LLM workflows, MCP/tooling, memory, RAG/context engineering;
- **product engineering** — CRM, ERP, internal operating systems, dashboards, SaaS workflows;
- **AI-first web production** — deterministic website generation, QA gates, design systems and deployment pipelines;
- **human-in-the-loop automation** — agents that assist, execute and verify without losing control.

> I don’t build random AI demos. I build operating systems for AI-assisted production.

---

## Currently building

### 🚀 [Aigentos / aiCRM](https://aigentos.tech)

**Agentic CRM for real small-business workflows.**  
Autonomous AI agents qualify leads, draft follow-ups, analyze deal risks, update pipelines and keep CRM memory in sync while humans stay in control.

Core idea:

```text
User intent → business context → AI plan → CRM action → reminders → memory
```

### 🧠 GovardOS

An internal AI-first control plane for projects, agents, artifacts, workflows and quality gates — built to make AI-assisted development observable, repeatable and production-ready.

### ⚙️ Website Engine

AI-first website generation pipeline: brief → architecture → sections → HTML/Tailwind → QA → deployable artifacts.

### 🧩 Agentic Workflow Stack

OpenCode-style agents, MCP tools, RAG/context layers, deterministic checks, reviewer/tester gates and documentation-first delivery.
